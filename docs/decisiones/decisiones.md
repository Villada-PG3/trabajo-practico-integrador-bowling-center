Decisión #001

El costo de una reserva dependerá de una tarifa configurable asociada a la pista.

Decisión #002

La reserva corresponderá a una sola pista.
El sistema no modelará reservas multi-pista en esta versión.

Decisión #003

El sistema no impondrá un límite duro de jugadores por pista.
La pista podrá configurarse con una capacidad máxima por motivos físicos y operativos, y esa capacidad se usará como validación al reservar.

Decisión #004

Las tarifas variarán según el día y la hora.
El dueño podrá configurarlas por pista y actualizará las tarifas vigentes semanalmente.

Decisión #005

El sistema de reservas se organizará como un calendario por día y franja horaria.
Desde allí se visualizarán las pistas disponibles, se realizará la reserva sobre un turno horario determinado y se calculará el precio correspondiente.
